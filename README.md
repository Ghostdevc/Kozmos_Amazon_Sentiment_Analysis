# Amazon Product Review Sentiment Analysis

This project performs sentiment analysis on Amazon product reviews to classify them as positive or negative using NLP techniques.

## Project Overview

- Loads and preprocesses Amazon review text data
- Uses text cleaning, tokenization, and vectorization (e.g., TF-IDF)
- Trains machine learning models for sentiment classification
- Evaluates model performance with accuracy, precision, recall
- Visualizes sentiment distributions and word importance

## Tech Stack

- Python
- Pandas, NumPy
- scikit-learn
- NLTK or SpaCy (for NLP preprocessing)
- Matplotlib, Seaborn

## How to Run

1. Clone the repository:
git clone https://github.com/Ghostdevc/Kozmos_Amazon_Sentiment_Analysis.git
cd Kozmos_Amazon_Sentiment_Analysis

2. Install dependencies:
pip install -r requirements.txt

3. Run the sentiment analysis script:
python sentiment_analysis.py

## Notes

- Suitable for text classification and sentiment mining beginners
- Can be extended to other product categories or languages
